Cấu Hình Server / Key API

Mặc định ứng dụng chạy ở chế độ Mô Phỏng Render Trực Quan (Client AI Engine) mượt mà không cần API. Bật công tắc bên dưới và điền URL Server để kết nối AI thật (Server chạy Stable Diffusion / API tương thích AUTOMATIC1111).

Server AI của bạn phải bật CORS cho phép trình duyệt gọi trực tiếp, nếu không trình duyệt sẽ chặn request. Key được lưu trong trình duyệt (localStorage) của bạn — không dùng chung máy tính công cộng.
